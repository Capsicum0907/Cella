## ページ

Cella は一度に1ページを表示します。右上の矢印でページを送り、隣の数字が現在のページと総数を示します。マウスホイールでも送れますが、効くのは枠と蓋の上だけです。スロットの上のホイールは他の Mod のものなので取りません。

1ページの大きさは形とウィンドウで決まります。既定ではクライアントがウィンドウに合わせるので、画面が広いか GUI の拡大率が小さいほど一度に多く映り、ページ数は減ります。[設定](config.ja.md)で切れます。

## パーティション

Semi-Perfect 以降はチェストをパーティションに分けられます。それぞれが独立した入れ物です。入れたものはそのパーティションから出ません。満杯のパーティションには、他が空いていてもそれ以上入りません。

チェストは全体を占めるパーティション1つから始まります。2つ目に容量を渡すには、先に1つ目から容量を戻します。

大きさは LC で数えます。1 LC はラージチェスト1つ分の54スロットです。パーティションは一覧の順に前から並び、合計はチェストの容量を超えられません。各形の LC は[形](forms.ja.md)の表にあります。

### 一覧

パーティションが2つ以上あると、チェストを開いたときに一覧が出ます。各行には左端の色・名前・使用率が出ます。1回クリックすると右に中身が出て、もう1回クリックすると開きます。パーティションが1つだけのときは一覧を飛ばしてそのまま開きます。戻るボタンで一覧へ行けます。

一覧の一番上の Everything は全パーティションをまとめて開きます。中身はチェストの並び順でまとめて並びます。同じアイテムでもパーティションが違えば別の枠に出て、一覧の順に隣り合います。取り出しはいつも通りできます。入れるには、先に色のチップで入れ先のパーティションを選びます。選ぶまでは何も入りません。選んだチップをもう一度押すと選択が外れます。

パーティションの中でも Everything でも、マウスを乗せた枠は属するパーティションの色で縁取られます。名前の付いたパーティションを開いているときは、上のタイトルにチェストの名前ではなくパーティションの名前が出ます。

### 編集

一覧の編集ボタンで編集画面が開きます。各行の項目は次の通りです。

| | |
|---|---|
| 色 | 染料の16色から選ぶ |
| 名前 | 20文字まで |
| 占有率 | チェスト全体のうちの割合 |
| LC | 大きさ。数字を打ち込む |
| 使用率 | どれだけ埋まっているか |

- 中身が入りきらない大きさや、合計がチェストの容量を超える大きさは受け付けません。どちらが理由かをメッセージで出します。
- 行のボタンで、使っていない容量を戻せます。
- 下の + で、容量0の空のパーティションが末尾に作られます。
- ゴミ箱で削除できます。空のパーティションだけです。最後の1つは削除できません。

⚠ 大きさを変えると、後ろのパーティションが中身ごと一緒にずれます。中身が消えたり混ざったりはしません。

### ホッパーとコンパレーター

ホッパーとレッドストーンコンパレーターが届くのは1つのパーティションだけです。既定は先頭のパーティションです。そのパーティションを削除すると、どこにも届かなくなります。

## 常に整列しています

中身は常に整列・統合された状態に保たれます。整列はパーティションごとに行われます。押すものはありませんし、片付ける必要もありません。

⚠ **枠を指定して置くことはできません。** どのスロットに入るかはアイテム自身が決めるので、画面は並べる格子ではなく取り出す一覧です。

左上のボタンが並び順を選びます。押すと順に切り替わり、ツールチップが現在の順序を出します。

| 並び順 | まとめ方 |
|---|---|
| item id | 登録名。`andesite_wall` が `baked_potato` より前 |
| name | 画面に出る名前 |
| mod | Mod ごと、その中は登録名 |

⚠ **name には言語が必要で、整列はサーバー側で行われます。** シングルプレイと LAN 公開では本人のゲームがサーバーなので、本人の言語のまま正しく並びます。専用サーバーではバニラのアイテムが英語、Mod のものが翻訳鍵になります。専用サーバーに置くチェストは item id のままが無難です。

並び順はチェストに保存され、全パーティションに同じ順序が使われます。ホッパーもレッドストーンコンパレーターも、他の誰とも同じスロットを見ます。

## 検索

Semi-Perfect 以降は、タイトルの左の虫眼鏡でその行が検索欄になります。該当したものだけが、同じようにページ送りで表示されます。

語は登録名と表示名の両方に当たります。アンダースコアは空白として扱うので、`diamond sword`・`diamond_sword`・`sword` のどれでも見つかります。

結果の最後のページは、そのページの終わりまで空きスロットで埋められます。置く場所が常にあり、結果の終わりが目で分かります。1件も無いときは枠を出さず、代わりに文言が出ます。

結果はチェストの変化に追従します。最後の1個を取り出せばその枠は消え、新しく入れれば該当する位置に現れます。

## 移動の2ボタン

自分のインベントリの隣にあります。矢印はアイテムが動く向きです。

| ボタン | クリック | シフト |
|---|---|---|
| ↑ | 入れる：チェストに既にある種類だけ | 入れる：手に持っているもの以外すべて |
| ↓ | 出す：自分が持っている種類だけ | 出す：入るだけ |

パーティションを開いているときは、どちらも画面のページではなくそのパーティション全体に届きます。表の「チェスト」はそのパーティションのことです。Everything では↑は選んだパーティションに入れ、↓は全パーティションから出します。シフトクリックでの投入は↑と同じ所へ入ります。

手に持っているものは取られません。防具・オフハンド・Curios の枠にも触れません。

## 記録されるもの

チェストは自分の画面を通った出し入れを記録します。種類・前の数・後の数の3つです。エンチャント等の成分も区別するので、エンチャントの本が「本」として記録されることはありません。

ホッパーなどの自動化は記録されません。

保持する件数は[設定](config.ja.md)の `history` です。

⚠ 表示はまだありません。集めて保存するところまでです。
